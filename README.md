# Operations CRM Case Study

A custom CRM and workflow platform designed to support internal operations, customer tracking, team coordination, and reporting.

## Overview
This system was built to improve operational visibility, workflow discipline, and day-to-day execution across internal business processes.

## Core Capabilities
- Customer record management
- Workflow tracking
- Team visibility and coordination
- Reporting and monitoring
- Internal process management

## My Role
I led the design, structure, and implementation of the system, translating operational needs into a practical digital tool.

## Why It Was Built
The goal was to replace fragmented manual processes with a more structured, visible, and accountable operating system.

## Stack
- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Sheets
- PHP

Production code is private because it is tied to a live business environment.
